Uma rede de lojas de vestuário precisa de um sistema de controle de estoque em tempo real para evitar rupturas de produtos nas prateleiras. O cenário atual sofre com desvios e falta de atualização nas vendas físicas e online. O sistema deve registrar o catálogo de produtos com variações de tamanho e cor. O Estoquista registra a entrada de novas caixas enviadas pelos fornecedores. A cada venda realizada no caixa (PDV), o sistema deve dar baixa automática na quantidade do item correspondente. Se o estoque de um produto atingir o limite mínimo estipulado, o sistema deve sinalizar o item como "Reposição Urgente" no painel do gerente. Apenas o Gerente pode autorizar devoluções de mercadorias com reembolso. A API precisa responder com altíssima velocidade para evitar filas no pagamento.
